SOBRE O PROJETO

Como funciona?

Etapas do CASE 4 — Academia (Mensalidade Personalizada).

01

Organização dos dados

São utilizados 40 registros fictícios. A variável X representa os dias de treino por semana, e Y representa a mensalidade em reais.

02

Cálculo dos coeficientes

O JavaScript calcula as médias, o numerador, o denominador, β₁ e β₀, aplicando manualmente as fórmulas de mínimos quadrados.

03

Previsão da mensalidade

Quando o cliente informa sua frequência, o sistema utiliza a equação Y estimado = β₀ + β₁X para estimar o preço.

04

Interpretação e comparação

Os coeficientes podem ser comparados com os resultados de np.polyfit(X, Y, 1) no Python. Os métodos devem apresentar resultados equivalentes.

Importante para a avaliação

Este é um projeto acadêmico com dados fictícios. O modelo usa apenas a frequência semanal para prever a mensalidade. Idade, objetivo e plano são dados informativos e não alteram a previsão. Uma aplicação comercial exigiria dados reais, validação e treinamento com as variáveis relevantes.
